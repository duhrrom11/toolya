# Toolya

Alltagstools auf https://toolya.app, veröffentlicht über GitHub Pages aus `main`.

Die Arbeitsfassung `feature/mascot-universe-release` führt zwölf Tools unter englischen Routen zusammen und ergänzt beide flauschigen Begleiter, 16 Gefühlsvarianten, Arbeitsoutfits, freiwillige Ko-fi-Aufrufe und ein Kitzel-Easter-Egg. Vor der Veröffentlichung müssen die isolierten CI-Gates erfolgreich sein.

Die bestehende Wishlist unter `/tools/wishes/` und ihr Amazon-Importer bleiben erhalten. Gemeinsames Supabase-Projekt: `yheogmeaosuigyaxkwth`. Bisherige Helferlein-Konten, Daten und Hosting werden nicht überschrieben oder automatisch übertragen.
