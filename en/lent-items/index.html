Track lent items and their return dates

Keep a record of things you have lent out, who has them, planned return dates, deposits and completed returns.

Language availability: This guide is in English. The linked application has not yet been fully translated; some controls and account messages may appear in German. Some features require a free Toolya account.

Getting started

  1. Choose an item and borrower

    Sign in and start a lending record. Select an item from your inventory and an existing contact, or enter a new person's name.

  2. Record the lending and return dates

    Enter the date you handed over the item. Add an agreed due date, optional deposit, note or photograph, then save the record.

  3. Mark returns and update dates

    Find the loan in the overview. Edit the agreed return date if plans change and mark the item returned when you receive it back.

A useful lending list

Record the item, borrower, handover date and planned return. Add accessories if they need to come back too—for example, a power tool with its charger.

Calendar entry

Where supported, add the planned return date to your calendar. A due date and the actual loan duration are not necessarily the same.

Track deposits separately

A noted deposit is part of the lending record; review whether it is still outstanding when you close the loan.

Frequently asked questions

Must the item already exist in inventory?

No. The tool can ask for the item name when you save a new loan.

Can I change the due date?

Yes. Edit the lending record to reflect a new agreement.
