⭐ Your personal overview

Personal Toolya dashboard for favourites, tasks and reminders

Keep favourite tools, recently used tools, to-dos and dated reminders together in your Toolya dashboard.

Open my dashboardAll tools

Language availability: This guide is in English. The dashboard application is not yet fully translated; some controls, account states and errors still appear in German.

Start with your favourite tools

Find a tool you often use on the Toolya homepage, then select the star to save it as a favourite. Open the dashboard and use the favourites panel to return to it. Select the star again to remove the favourite.

Return to recently opened tools

The dashboard also shows recently used tools. This is useful if you alternate between several tasks and do not want to search the tool catalogue every time.

Make and complete a task

Write a clear task under your personal to-do list, then add it. For example, create “Read electricity meter”. Tick the checkbox when you have completed it. You can record the actual reading separately in the meter-reading tool.

Set reminders with a date and time

Add a reminder such as “Check the balcony plants”, choose a date and time, then save it. The dashboard shows due reminders when you open it. It does not currently promise automatic push notifications while your browser is closed.

Shared shopping lists and watering tasks

Sign in to view your own shopping items alongside items from households you can access. Each item shows where it came from. Ticking off a household item also marks it bought in the roommate organizer. Use the print option for a list of outstanding items. Plant-watering tasks can also appear through Toolya Connect when the account and tool permissions allow it.

Where is my dashboard data stored?

Favourites and recently used tools stay in the current browser profile. Tasks and reminders also stay in the browser while signed out. After signing in, you can import local tasks and reminders if Toolya finds them. Account-saved tasks and reminders are available on other devices using the same account.

Prepare for your next meter reading

Save Meter readings as a favourite, create a “Read the meter” task and add a reminder for the day you plan to take the reading. Open the tool from your favourites and save the reading. Then tick off both the task and the reminder.

To move a reminder, create one for the new time and remove the old one once the new entry appears.

Get started

Open the existing Toolya dashboard with your account. Switching languages does not create a separate profile or modify your chosen mascot.
