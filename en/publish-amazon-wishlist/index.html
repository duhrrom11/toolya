Publish and find a public Amazon wish list

Learn how to share an eligible public Amazon wish list in Toolya's directory while continuing to manage list items on Amazon.

Open the public wish-list directoryAll tools

Language availability: This guide is in English. The linked application has not yet been fully translated; some controls and account messages may appear in German. Some features require a free Toolya account.

Getting started

  1. Create or open your list on Amazon

    Choose a regular Amazon wish list and add the items there. Amazon continues to host and manage the items on the list.

  2. Check the sharing link

    Adjust the list's visibility at Amazon, copy its viewing link and test the link while signed out of Amazon. Do not share an editing or private link by mistake.

  3. Add an eligible list to Toolya

    Sign in to Toolya, choose the profile type and add the regular public wish-list URL. Review the preview before publishing.

What will be visible?

Your name or organisation name, country and linked lists can be publicly visible in Toolya's directory. A city or region you add may also appear. Choose carefully what you share.

Finding lists

Visitors can use the directory to search for a public wish list. The ability to find a list depends on its public profile and valid listing details.

Removing your listing

You can remove a list from Toolya or remove the profile. Removing Toolya's reference does not delete the original list from Amazon.

Partner links

Some links to Amazon may be marked affiliate links. The product list and Amazon account remain governed by Amazon's own service.

Frequently asked questions

Are baby and wedding registries the same as regular wish lists?

No. The Toolya directory form described by the German guide accepts direct links to regular Amazon wish lists. Baby and wedding registry links may be shared directly at Amazon.

Do visitors need a Toolya account to search?

Public directory search is intended to be accessible without signing in.

Copy the full view-only link

Open your regular wish list on Amazon and set its visibility to Public. Use the sharing or invitation menu and choose view-only access if prompted. Open the link in a private browser window. If a short link redirects to your list, copy the full address from the browser after the redirect. A direct link can contain /hz/wishlist/ls/.

Preview, search and update a public profile

Choose an individual or organisation profile. Enter the name and country. A city or region is optional. You can add up to five lists. Review the preview before saving because the profile details can appear in the public directory.

Search by name and try the country filter when several results look similar. You can bookmark a result in the current browser. If you remove one of several lists from your profile, save the profile again. Use the report option for a directory entry with a wrong name or a list that is no longer public.

Open the browser tool

Use your existing Toolya account; this is the same application as the German version. Switching the language does not create a separate account or translate your saved personal data.
